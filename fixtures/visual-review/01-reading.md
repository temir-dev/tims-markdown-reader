# A quiet place to read

The agent has finished its work. There is no dashboard to monitor and no form to complete. There is only a short document explaining what changed, what was learned, and what comes next.

A good reading page should make that easy. The title gives you a starting point; paragraphs have enough room to breathe; a heading appears just when you need a new landmark. You can skim the page first, then return to the part that matters.

## What changed today

We revised the onboarding notes so a new contributor can run the example without guessing which folder to open. The instructions now begin with one concrete task, followed by an explanation of the result. **Important details stand out**, while *small asides remain quiet*. An old ~~temporary workaround~~ has been removed.

The longer paragraph is intentional. Try changing the font size while you are partway through it. The page should stay readable, the headings should scale with the text, and the content should remain comfortably inside the window. In a very wide window, Centered keeps the prose in a reading column, while Full Width lets the text use more of the available space. Neither option centers the words themselves: normal paragraphs remain aligned to the left.

### Small details worth noticing

- Bold text should feel distinct without becoming heavy.
- Italic text should remain easy to read.
- Inline `code_like_this()` should stay monospaced.
- Links should be visible: [return to the sample list](00-start-here.md).

2. Read the result.

## Words from different places

Café, naïve, résumé, São Paulo, Zürich. Curly quotes: “read this”; apostrophes: it’s Tim’s reader. Dashes: a short pause – and a longer pause — both should look natural.

日本語の文章も表示できます。中文段落也应该清晰可读。한국어 문장도 확인해 보세요.

Emoji can appear in agent notes too: 🌿 📖 ✅. Font fallback may look different from the surrounding letters, but it should not leave broken boxes.
