# Make yourself comfortable

A small collection of invented Markdown documents for trying Tim’s Markdown Reader.

Open **Settings…** from the app menu, or press **⌘,**. Try **Serif**, move the **Text size** slider, then switch between **Centered** and **Full Width**. Widen the document window to make the layout difference more obvious. Everything updates as you read.

## Pick something to read

1. [A quiet reading page](01-reading.md) — paragraphs, headings, lists, quotes, and Unicode.
2. [An agent handoff](02-agent-handoff.md) — checklists, tables, code, and long lines.
3. [A plan in diagrams](03-diagrams.md) — flowchart, sequence diagram, and state diagram.
4. [Images and navigation](04-images-and-links.md) — a local image, a missing image, and heading links.

## A quick lap

- Keep two documents open and adjust the settings. Both should change.
- Try the smallest and largest text sizes, then **Restore Defaults**.
- Make a document window narrow, then wide. Tables and code should scroll when necessary.
- Press **⌘F** and search for a word on the page.
- Follow a link, then use **⌘[** to go back.
- If you normally switch macOS between light and dark, compare both appearances.
- Quit and reopen the preview to check that your chosen reading settings return.

Tell me which sample and setting you were using if anything looks awkward. These files are just test material; you can read and close them normally.
