# Privacy

Tim’s Markdown Reader displays local Markdown files. It has no account, telemetry SDK, advertising, document-upload feature or AI service. Reading and Mermaid diagram rendering work offline. Remote document images are blocked. Clicking an allowed web or email link opens your browser or mail app; those apps and destinations have their own privacy practices. The app does not check for updates by itself: Check for Updates… only opens the download page in your browser when you choose it.

The app reads the documents you open and permitted relative images and linked Markdown files. It watches the current document for external changes. It does not edit or delete your source documents. Navigation history is limited to the current window and does not retain document contents as a persistent history. The WebKit data store is nonpersistent. Window geometry and reading preferences (font, text size and layout) are saved locally using macOS preferences.

macOS may retain normal system records such as file associations, preferences and crash diagnostics, according to your system settings. This app does not automatically send those records to its maintainer. GitHub has its own privacy practices for downloads and issue reports.

When reporting a bug, use a small invented example. Do not post private agent instructions, customer data, credentials or complete personal documents. Inspect screenshots and diagnostic logs before sharing them.
